# Honeywell GradeSenseAI

## AI-Powered Grade Change Intelligence for Paper Manufacturing

An industrial AI decision-support platform that predicts off-spec paper during grade transitions,
recommends corrective actions, explains every recommendation, and learns from operator feedback.

---

- Docker

- Health APIs

A runnable full-stack application with clean architecture.
